# Промт для Claude Code: мини-приложение invest-watch

Скопируй всё, что ниже линии, в Claude Code, открытый в папке нового пустого проекта.

---

Собери Telegram Mini App с ботом уведомлений для моего мониторинга акций и фондов недвижимости. Все данные пишет агент в GitHub-репозиторий `nubasikplayyt-dev/invest-watch`. Начни с того, что прочитаешь его целиком: `README.md`, `CRITERIA.md`, `AGENT.md`, `config/watchlist.json`, `config/universe.json`, `config/favorites.json`, `config/overrides.json`, `schema/event.schema.json`, `data/*/status.json`, `data/*/dividends.json`, `data/*/events.jsonl`, `feed/feed.json`. Структуру данных бери оттуда, ничего не придумывай поверх.

## Принцип
Приложение показывает только факты и оценки по моим критериям из репозитория. Никаких собственных оценок, рейтингов аналитиков, целевых цен, «сигналов», прогнозов и рекомендаций — ни в интерфейсе, ни в текстах, ни в подсказках.

## Навигация
Нижняя панель вкладок:
1. **Избранное** — главный экран, открывается при запуске.
2. **Россия** 🇷🇺
3. **США** 🇺🇸
4. **Китай** 🇨🇳
5. **Настройки**

Список рынков бери из `watchlist.json → markets[]`, а не хардкодь: если там появится новый рынок, вкладка должна добавиться сама.

## Экран «Избранное»
- Сверху переключатель: **Бумаги** / **Новости**.
- «Бумаги» — карточки избранных бумаг: картинка, тикер, название, флаг рынка, тип (акция / фонд недвижимости), цветной бейдж вердикта, последняя цена с изменением за день, дивдоходность и её отношение к порогу рынка (например «12,7% / порог 5%»). Перетаскиванием можно менять порядок.
- «Новости» — лента событий только по избранным бумагам из `events.jsonl`, новые сверху. Фильтры: тип бумаги (все / акции / фонды недвижимости), конкретная бумага (выпадающий список с поиском), важность (critical / high / medium), тип события (отчёт, дивиденды, долг, санкции и т. д.). У каждого события: дата, бумага, заголовок, сводка, ключевые метрики чипами, ссылки на источники.
- Пустое состояние: подсказка «Добавьте бумаги звёздочкой во вкладках рынков».

## Вкладки рынков (Россия / США / Китай)
- Сверху сегмент: **Акции** / **Фонды недвижимости**.
- Поиск по тикеру и названию.
- Фильтры: вердикт (buy_zone, hold, watch, do_not_buy, sell_candidate); «проходит порог дивдоходности»; «только сырьевые / без сырьевых»; «только в составе индекса» (`in_universe`).
- Сортировка: по дивдоходности, по вердикту, по названию, по дате обновления оценки.
- Список карточек как в «Избранном», у каждой — звёздочка: добавить в избранное или убрать.
- Бумаги без `status.json` показываются с пометкой «ещё не проверена».

## Экран бумаги (по нажатию на карточку)
1. **Шапка:** картинка, название, тикер, ISIN, биржа, рынок, тип, вердикт, дата последней оценки, звёздочка избранного.
2. **График цены — линия, не свечи.** Периоды: 1М, 6М, 1Г, 5Л, Всё. Касание показывает цену и дату. Линия зелёная, если цена за период выросла, красная — если упала. Под графиком — изменение за выбранный период в процентах.
3. **Дивиденды по годам:** столбчатая диаграмма сумм за год (`dividends.json → by_year`) за 10 лет и таблица выплат (дата отсечки, сумма, доходность к цене на дату отсечки, если цена есть). Для фондов недвижимости — те же выплаты по месяцам.
4. **Критерии:** таблица C1–C8 и P1–P3 из `status.json` со статусом-иконкой (pass ✓ / warn ! / fail ✕ / n/a —) и пометкой. Если для критерия есть запись в `overrides.json`, показывай её с меткой «решение владельца». Нажатие на код — расшифровка из `CRITERIA.md`.
5. **Метрики:** `status.json → metrics` с датой.
6. **Что отслеживается:** поле `watch`.
7. **События:** лента из `events.jsonl` этой бумаги с фильтром по типу.

## Картинки бумаг
- У каждой бумаги в `watchlist.json` есть поле `domain` (сайт компании или УК). Логотип загружай по домену через публичный сервис логотипов или иконок сайтов. Выбери сервис, который работает без ключа, и кэшируй картинки.
- Если логотип не загрузился — заглушка: круг с первыми буквами тикера, цвет по хэшу тикера.
- Поле `logo` в `watchlist.json`, если оно появится, имеет приоритет над доменом.

## Избранное — синхронизация с агентом
- Избранное хранится в `config/favorites.json` репозитория: агент по нему решает, что мониторить 4 раза в сутки.
- Нажатие на звёздочку сразу меняет интерфейс (оптимистично) и отправляет изменение в Cloudflare Worker. Воркер коммитит обновлённый `favorites.json` через GitHub API токеном с правом записи только в этот репозиторий. Токен — секрет воркера, во фронтенде его нет.
- Воркер проверяет, что запрос пришёл из моего Telegram: валидирует `initData` Mini App подписью бота и сверяет user id с разрешённым (секрет `ALLOWED_TG_USER_ID`).
- Если запись не удалась — откат звёздочки и короткое сообщение.

## Цены и дивиденды для графиков
- Россия: публичный API Мосбиржи (ISS) — история цен и дивиденды. Ключ не нужен.
- США и Китай (Гонконг, Шанхай, Шэньчжэнь): выбери бесплатный источник исторических цен, который покрывает все три биржи. Если нужен ключ — храни его в секретах воркера и напиши в README, где его получить.
- Все запросы к источникам цен идут через воркер с кэшем: дневная история — 6 часов, последняя цена — 15 минут.
- Если в `dividends.json` пусто, а источник цен отдаёт дивиденды, показывай их с пометкой источника. Приоритет — данные из репозитория.

## Уведомления
- Бот в Telegram, команда `/start` регистрирует мой chat_id.
- GitHub Action в репозитории данных (`.github/workflows/notify.yml`): на каждый push в `main` находит новые строки в `data/*/events.jsonl` с `notify: true` по **избранным** бумагам и отправляет их в бота (`sendMessage`, HTML): эмодзи важности, бумага, заголовок, 1–2 строки сводки, кнопка «Открыть» с deep link `startapp=<asset_id>` прямо в экран бумаги.
- Команды бота: `/mute <тикер>`, `/unmute <тикер>`, `/muted` — список заглушенных хранится в KV воркера, Action его учитывает.
- Секреты: `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` — в GitHub Secrets и в воркере, нигде в коде.

## Настройки
- **Тема:** Тёмная / Светлая / Системная. «Системная» следует теме Telegram и меняется на лету. Выбор сохраняется в Telegram CloudStorage.
- Ссылка на репозиторий, дата последнего обновления данных (`feed.json → generated_at`), кнопка «Обновить данные».

## Техника
- Vite + React + TypeScript, `@telegram-apps/sdk-react`, графики — лёгкая библиотека с линейными графиками, без свечей. Вёрстка под ширину телефона.
- Данные репозитория читать через воркер (репозиторий может стать приватным): `GET /repo/<path>` проксирует GitHub API токеном только на чтение. Кэш 5 минут, кнопка «Обновить».
- Список рынков, типов бумаг и сами бумаги — только из `watchlist.json`. Добавление новой бумаги, рынка или типа не должно требовать правок кода.
- Валидация `events.jsonl` по `schema/event.schema.json` (zod или ajv). Битая строка пропускается, экран не падает.
- Хостинг фронтенда: GitHub Pages или Cloudflare Pages, деплой через Actions.
- Язык интерфейса — русский, даты «30 окт 2026», числа с пробелом-разделителем тысяч и запятой.
- Без аналитики, трекеров и сторонних шрифтов.
