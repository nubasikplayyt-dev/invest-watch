# Промт для Claude Code: Android-приложение invest-watch

Скопируй всё, что ниже линии, в Claude Code, открытый в папке нового пустого проекта.

---

Собери нативное Android-приложение для моего мониторинга акций и фондов недвижимости. Все данные пишет агент в GitHub-репозиторий `nubasikplayyt-dev/invest-watch`. Начни с того, что прочитаешь его целиком: `README.md`, `CRITERIA.md`, `AGENT.md`, `config/watchlist.json`, `config/universe.json`, `config/favorites.json`, `config/overrides.json`, `schema/event.schema.json`, `data/*/status.json`, `data/*/dividends.json`, `data/*/events.jsonl`, `feed/feed.json`. Структуру данных бери оттуда, ничего не придумывай поверх.

Приложение для одного пользователя — меня. Публикация в Google Play не нужна: установка из APK.

## Принцип
Приложение показывает только факты и оценки по моим критериям из репозитория. Никаких собственных оценок, рейтингов аналитиков, целевых цен, «сигналов», прогнозов и рекомендаций — ни в интерфейсе, ни в текстах.

## Навигация
Нижняя панель (Material 3 NavigationBar):
1. **Избранное** — главный экран, открывается при запуске.
2. **Россия** 🇷🇺
3. **США** 🇺🇸
4. **Китай** 🇨🇳
5. **Настройки**

Список рынков бери из `watchlist.json → markets[]`, а не хардкодь: если там появится новый рынок, вкладка должна добавиться сама.

## Экран «Избранное»
- Сверху вкладки: **Бумаги** / **Новости**.
- «Бумаги» — карточки избранных бумаг: картинка, тикер, название, флаг рынка, тип (акция / фонд недвижимости), цветной бейдж вердикта, последняя цена с изменением за день, дивдоходность и её отношение к порогу рынка (например «12,7% / порог 5%»). Порядок меняется перетаскиванием.
- «Новости» — лента событий только по избранным бумагам из `events.jsonl`, новые сверху. Фильтры: тип бумаги (все / акции / фонды недвижимости), конкретная бумага (выпадающий список с поиском), важность (critical / high / medium), тип события. У события: дата, бумага, заголовок, сводка, ключевые метрики чипами, ссылки на источники (открываются в Custom Tabs).
- Пустое состояние: подсказка «Добавьте бумаги звёздочкой во вкладках рынков».
- Pull-to-refresh.

## Вкладки рынков (Россия / США / Китай)
- Сверху сегмент: **Акции** / **Фонды недвижимости**.
- Поиск по тикеру и названию.
- Фильтры: вердикт (buy_zone, hold, watch, do_not_buy, sell_candidate); «проходит порог дивдоходности»; «только сырьевые / без сырьевых»; «только в составе индекса» (`in_universe`).
- Сортировка: по дивдоходности, по вердикту, по названию, по дате обновления оценки.
- Карточки как в «Избранном», у каждой звёздочка — добавить в избранное или убрать.
- Бумаги без `status.json` — с пометкой «ещё не проверена».

## Экран бумаги
1. **Шапка:** картинка, название, тикер, ISIN, биржа, рынок, тип, вердикт, дата последней оценки, звёздочка, переключатель «уведомления по этой бумаге».
2. **График цены — линия, не свечи.** Периоды: 1М, 6М, 1Г, 5Л, Всё. Касание показывает цену и дату. Линия зелёная, если цена за период выросла, красная — если упала. Под графиком — изменение за период в процентах.
3. **Дивиденды по годам:** столбчатая диаграмма сумм за год (`dividends.json → by_year`) за 10 лет и таблица выплат (дата отсечки, сумма, доходность к цене на дату отсечки, если цена есть). Для фондов недвижимости — выплаты по месяцам.
4. **Критерии:** таблица C1–C8 и P1–P3 из `status.json` со статусом (pass ✓ / warn ! / fail ✕ / n/a —) и пометкой. Если для критерия есть запись в `overrides.json`, показывай её с меткой «решение владельца». Нажатие на код — расшифровка из `CRITERIA.md`.
5. **Метрики:** `status.json → metrics` с датой.
6. **Что отслеживается:** поле `watch`.
7. **События:** лента из `events.jsonl` этой бумаги с фильтром по типу.

## Картинки бумаг
- У каждой бумаги в `watchlist.json` есть поле `domain` (сайт компании или УК). Логотип загружай по домену через публичный сервис логотипов или иконок сайтов, работающий без ключа. Загрузка и кэш — Coil.
- Если логотип не загрузился — заглушка: круг с первыми буквами тикера, цвет по хэшу тикера.
- Поле `logo` в `watchlist.json`, если появится, имеет приоритет над доменом.

## Данные и синхронизация
- Репозиторий читается через GitHub REST API (`/repos/{owner}/{repo}/contents/...`, для больших списков — Git Trees API) с ETag-кэшем, чтобы не тратить лимиты.
- Доступ: fine-grained personal access token GitHub с правами только на этот репозиторий (Contents: read and write). Токен вводится один раз на экране настройки при первом запуске и хранится в EncryptedSharedPreferences (Android Keystore). В коде и в репозитории токена нет. Работает и с приватным репозиторием.
- Локальное хранилище — Room: все бумаги, статусы, события, дивиденды и цены. Приложение полностью работает офлайн на последних загруженных данных и показывает дату обновления.
- **Избранное** хранится в `config/favorites.json` репозитория: агент по нему решает, что мониторить 4 раза в сутки. Звёздочка сразу меняет интерфейс и ставит запись в очередь; WorkManager коммитит обновлённый файл через Contents API (с проверкой `sha`, при конфликте — перечитать и смержить). Без сети — отправка при появлении сети.

## Цены и дивиденды для графиков
- Россия: публичный API Мосбиржи (ISS) — история цен и дивиденды, без ключа.
- США и Китай (Гонконг, Шанхай, Шэньчжэнь): выбери бесплатный источник исторических цен, покрывающий все три биржи. Если нужен ключ — поле для него на экране настроек, хранение там же, где токен GitHub. В README напиши, где его получить.
- Кэш в Room: дневная история обновляется раз в 6 часов, последняя цена — не чаще раза в 15 минут при открытом экране.
- Если в `dividends.json` пусто, а источник цен отдаёт дивиденды, показывай их с пометкой источника. Приоритет — данные из репозитория.

## Уведомления
- Фоновая синхронизация через WorkManager каждые 30 минут (при наличии сети): забрать новые строки `events.jsonl` и `feed/feed.json`.
- Для новых событий с `notify: true` по **избранным** бумагам — локальное уведомление: важность (эмодзи), бумага, заголовок, 1–2 строки сводки. Нажатие открывает экран бумаги (deep link).
- Отдельные каналы уведомлений для `critical` и `high`, чтобы их можно было настроить в системе по-разному.
- Выключатель уведомлений для каждой бумаги — на экране бумаги; общий выключатель и «тихие часы» — в настройках.
- Запрос разрешения POST_NOTIFICATIONS (Android 13+) при первом добавлении в избранное, с объяснением зачем.
- Учесть ограничения энергосбережения: в настройках кнопка, открывающая системное исключение из оптимизации батареи, с пояснением.

## Настройки
- **Тема:** Тёмная / Светлая / Системная, переключение на лету, выбор сохраняется в DataStore. Поддержка Material You (динамические цвета) на Android 12+ с выключателем.
- Токен GitHub и ключ API цен: ввод, проверка, удаление.
- Дата последней синхронизации, кнопка «Обновить сейчас».
- Уведомления: общий выключатель, тихие часы.

## Техника
- Kotlin, Jetpack Compose, Material 3, архитектура MVVM + Repository, Hilt, Kotlin Coroutines/Flow, Retrofit/OkHttp + kotlinx.serialization, Room, DataStore, WorkManager, Coil, Navigation Compose. Графики — Vico (линейные и столбчатые, без свечей).
- minSdk 26, targetSdk — последний стабильный.
- Список рынков, типов бумаг и сами бумаги — только из `watchlist.json`. Новая бумага, рынок или тип не требуют правок кода.
- Валидация событий по `schema/event.schema.json` при парсинге: битая строка пропускается, экран не падает.
- Язык интерфейса — русский. Даты «30 окт 2026», числа с пробелом-разделителем тысяч и запятой.
- Без аналитики, трекеров, рекламы и Firebase.
- Сборка APK: GitHub Actions в репозитории приложения собирает подписанный release APK и публикует его в GitHub Releases. Ключ подписи — в Secrets. В README — как скачать и установить APK на телефон.
