# invest-watch

Мониторинг бумаг консервативного портфеля по собственным критериям владельца. Агент по расписанию ищет новости, отчёты и дивиденды, отбирает значимое, оценивает по критериям и коммитит сюда. Мини-приложение в Telegram читает этот репозиторий и присылает уведомления о важном.

## Структура
| Путь | Что там |
|---|---|
| `CRITERIA.md` | Критерии качества (C1–C8), цены входа (P1–P3) и исключения владельца |
| `AGENT.md` | Инструкция для агента на каждый запуск |
| `config/watchlist.json` | Разделы по странам и бумаги в них |
| `data/<id>/status.json` | Текущая оценка бумаги по критериям и вердикт |
| `data/<id>/events.jsonl` | Значимые события, одна строка — одно событие |
| `schema/event.schema.json` | Формат события |
| `feed/feed.json` | Сводная лента последних событий для приложения |
| `digests/YYYY-MM-DD.md` | Сводка каждого запуска |
| `docs/MINI_APP_PROMPT.md` | Промт для Claude Code на создание мини-приложения |

## Сейчас отслеживаются
Раздел «Российские акции»: Сбербанк (SBER), Газпром нефть (SIBN), ФосАгро (PHOR), ЗПИФ Парус-СБЛ (RU000A104172).

## Как добавить бумагу
1. Добавь объект в `assets[]` нужного раздела `config/watchlist.json`.
2. Создай `data/<id>/status.json` (можно пустой шаблон с `asset_id`) и пустой `data/<id>/events.jsonl`.
3. Следующий запуск агента заполнит оценку.

## Как добавить страну
Добавь объект в `sections[]` с полями `id`, `title`, `country` (ISO-3166), `currency`, `yield_floor_pct` (порог дивдоходности в этой валюте: для USD/EUR/CHF около 1%).

Это не инвестиционная рекомендация.
